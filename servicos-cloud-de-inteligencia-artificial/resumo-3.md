# 🤖 Laboratório 12: Introdução à IA Generativa

## 🎯 Objetivo

Explorar os conceitos e aplicações da **IA Generativa**, utilizando o **Azure OpenAI Service** para gerar textos de forma contextualizada.

## 🧪 Atividades Realizadas

1. **Criação do recurso Azure OpenAI**

   - Implantação e acesso ao Azure OpenAI Studio.

2. **Geração de Texto**

   - Uso de prompts para gerar respostas inteligentes com o modelo GPT.
   - Exploração de parâmetros como temperatura e frequência.

3. **Casos de Uso**
   - Criação de conteúdo, resumo automático, resposta a perguntas e reformulação de texto.

---

# 💡 Laboratório AI Studio 01: Explorando o Azure AI Studio

## 🎯 Objetivo

Familiarizar-se com o **Azure AI Studio**, uma plataforma low-code para criar, testar e implantar soluções com IA generativa.

## 🧪 Atividades Realizadas

1. **Exploração do ambiente**

   - Navegação pelas seções: Playground, Deployments, Content Filters, etc.

2. **Criação de Experimentos**

   - Geração de conteúdo com diferentes modelos (como GPT-3.5 e GPT-4).
   - Uso de instruções simples para orientar o comportamento do modelo.

3. **Salvando e compartilhando prompts**
   - Organização de testes para reutilização e colaboração.

---

# 🔐 Laboratório AI Studio 06: Filtros de Conteúdo no Azure AI Studio

## 🎯 Objetivo

Aprender a utilizar os **filtros de conteúdo (Content Filters)** no Azure AI Studio para evitar respostas inadequadas ou ofensivas.

## 🧪 Atividades Realizadas

1. **Configuração de Filtros**

   - Ajustes de segurança em categorias como linguagem imprópria, violência e sexualidade.

2. **Testes de Segurança**

   - Execução de prompts com potencial sensível para avaliar bloqueios.

3. **Práticas de Governança**
   - Garantia de conformidade ética e segura no uso de IA generativa.
