# 🧠 Laboratório 11: Azure AI Search

## 🎯 Objetivo

Aprender a utilizar o **Azure AI Search** para criar soluções inteligentes de busca sobre dados estruturados e não estruturados, enriquecendo os resultados com recursos cognitivos.

## 🧪 Atividades Realizadas

1. **Criação de um Serviço de Busca**

   - Provisão do recurso Azure Cognitive Search via portal Azure.

2. **Indexação de Documentos**

   - Upload de arquivos (PDFs, imagens etc.).
   - Criação de _indexers_ e _indexes_ para organizar os dados.

3. **Habilidades Cognitivas (Skillsets)**

   - Aplicação de habilidades como:
     - Extração de texto (OCR),
     - Análise de sentimento,
     - Reconhecimento de entidades nomeadas.
   - Conjunto de habilidades configurado para enriquecer os dados automaticamente.

4. **Consulta aos Dados com Interface de Busca**
   - Uso da ferramenta de _Search Explorer_ para fazer consultas textuais.
   - Visualização de metadados enriquecidos retornados pelas buscas.

## 🧠 Conceitos-Chave

- **Cognitive Search**: Combina indexação de dados com IA para permitir buscas mais inteligentes e contextuais.
- **Pipelines Cognitivos**: Fluxos de processamento que aplicam IA antes da indexação.
- **Skillsets**: Conjunto de habilidades aplicadas aos dados, como tradução, análise de sentimento, etc.

## ✅ Aplicações Reais

- Motores de busca personalizados para sites, intranets ou bases documentais.
- Enriquecimento de conteúdo para melhorar a descoberta de informações.
- Integração com bots, apps e dashboards inteligentes.
